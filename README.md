### 02 / Testing Workflow Skill · AI Coding 的验证工作流

**把“让 AI 测一下”变成有风险模型、有执行路径、有证据的工程流程。**

沉淀可复用的六步工作流：意图识别 → 影响面分析 → 风险建模 → 路径规划 → 精确执行 → 评估与知识沉淀。

- 区分需求意图、代码实现与实际运行行为，显式记录三者之间的冲突。
- 按风险选择验证深度，以真实 Bad Case 驱动回归资产与工作流迭代。
- 提供 Planner / Executor 分工指引、测试轮次模板与交接脚本，避免无边界探索和无证据结论。

`Agent Skills` `Risk-driven Testing` `Bad-case Feedback` `Validation Evidence`

[查看项目与使用说明 ↗](https://github.com/Lu-Yipeng/testing-workflow-skill)
